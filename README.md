# DuLog · 大日志检索工具

一个**轻量级**桌面日志查询工具：本地超大日志文件（GB 级）即时打开、流式检索、命中高亮；同时支持通过 **SSH 连接 Linux 服务器**浏览并检索远程日志。基于 **Tauri（Rust）+ React**，安装包仅数 MB，远小于 Electron 方案。

## 核心特性

- **超大文件友好**：本地文件采用内存映射（mmap）+ 稀疏行索引，不把整文件读入内存；前端虚拟滚动，无论文件多大只渲染可视行。
- **流式检索+高亮**：Rust `regex` 逐行扫描，仅保存命中行的「行号 + 命中区间」，命中即高亮；支持正则 / 纯文本、忽略大小写。
- **本地模式**：系统原生文件夹选择框，递归列出 `.log/.txt/.out` 文件。
- **SSH 远程模式**：复用系统 `ssh` 客户端（密钥 / ssh-agent / 密码登录），远程目录浏览、按行读取、`grep` 服务端检索，结果回传高亮。连接通过 `ssh` 的 ControlMaster 复用，避免每条命令重复握手。
- **懒加载查看**：打开文件即时可用，滚动时按需分页向后端请求行内容。

## 技术栈

| 层 | 选型 |
|---|---|
| 桌面壳 | Tauri 2（Rust，二进制 3–10 MB） |
| 前端 | React 18 + TypeScript + Vite |
| 后端逻辑 | Rust：mmap（`memmap2`）、正则（`regex`）、SSH（封装系统 `ssh` 的 ControlMaster） |
| 远程协议 | 系统 `ssh` / `grep` / `ls` / `stat` / `wc` / `tail` / `head` |

## 环境要求

- Rust 工具链（≥ 1.77）：https://rustup.rs
- Node.js（≥ 18）：https://nodejs.org
- Windows：已内置 WebView2 运行时（Win10/11 自带）；Linux/macOS 按 Tauri 文档安装系统依赖
- 远程模式：本机需有可用的 `ssh` 客户端（Windows 10+ 已自带 OpenSSH）

## 使用说明

1. **本地**：点击「本地文件夹」→「选择日志文件夹」，在左侧列表点击日志文件；顶部输入检索词，点击「检索」，命中行高亮，右侧结果列表可点击跳转。
2. **远程**：点击「SSH 远程」→「连接服务器」，填写主机/端口/用户；**推荐密钥登录**（`key_path` 填私钥路径，或已配置 ssh-agent）；也可填密码（见下方说明）。连接后浏览远程目录，点击日志文件即可检索。

## 性能说明

- 4 GB / 约 2000 万行日志：首次建索引（单次扫描）约数秒，常驻内存仅几十 MB（mmap + 稀疏索引）；全量检索在后台线程进行，命中结果即时高亮。
- 远程检索由服务端 `grep` 执行，仅回传命中行，网络传输量小。

## 远程认证说明

- **密钥 / ssh-agent（推荐，最稳定）**：保持默认即可。若私钥有密码短语且未注入 agent，请先 `ssh-add`。
- **密码登录**：通过 `SSH_ASKPASS_REQUIRE=force` 注入。在 Windows 上，系统 OpenSSH 自带 askpass 机制通常可用；若你的 OpenSSH 版本/环境不支持 askpass 脚本，会返回连接失败，此时请改用密钥登录。
- 连接使用 `ssh -M -f -N` 建立后台控制主连接（`ControlPersist=yes`），后续命令经同一套接字复用，断开时自动清理。

## 已知限制（v1）

- 远程模式每次按页读取为一次 `ssh` 调用（`tail -n +K | head -N`），超大文件跳转到文件末尾时存在一次从头扫描的网络往返延迟（可接受；后续可改为 SFTP 随机读取优化）。
- 远程 `grep -E` 使用服务端 ERE 方言做候选过滤，与 Rust 正则存在细微差异：本工具以客户端 Rust 正则为准重新计算高亮区间，方言差异导致 grep 未命中的行不会出现在结果中（典型搜索词无影响）。
- 单行超长（数 MB）场景未做特殊优化。
- 远程密码登录依赖系统 OpenSSH 的 askpass 能力；不支持该能力的环境请使用密钥登录。
